# PostgreSQL Docker Setup

This directory contains Docker configuration for the PostgreSQL database used by the FoodZrecipe application.

## Getting Started

1. Ensure Docker and Docker Compose are installed on your system.
2. Create a `.env` file in this directory with the following content (adjust as needed):


POSTGRES_USER=postgres
POSTGRES_PASSWORD=password
POSTGRES_DB=food_recipe
PGADMIN_DEFAULT_EMAIL=admin@admin.com
PGADMIN_DEFAULT_PASSWORD=admin
